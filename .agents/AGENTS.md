# Documentation Rule

From now on, whenever a feature changes the architecture, database, API, or security model, automatically update the corresponding file inside the `docs/` folder before considering the feature complete.

# Self-Verification Rule

After every phase or task, always self-assess by running, building, or testing the code to confirm it works without errors. Do not present work as complete until it has been verified end-to-end. Fix any issues before reporting to the user.
